# Code of Conduct

IDevelop Community Edition adopts the **Contributor Covenant, version 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful and inclusive, assume good intent, give and accept
constructive feedback, and put the community's interest first. Harassment,
discrimination and personal attacks are not tolerated in any project space —
issues, pull requests, discussions and events.

**Reporting.** Report unacceptable behaviour privately to the project
maintainers through GitHub (a private security advisory on this repository is
also acceptable when e-mail is not listed). All reports are reviewed and handled
confidentially. Maintainers may remove, edit or reject contributions and
temporarily or permanently ban contributors whose behaviour violates this code,
following the enforcement guidelines of the Contributor Covenant.
